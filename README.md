# 🌳 Gerenciador de Contatos com Árvore Binária em C

> Este projeto foi desenvolvido com o objetivo de praticar o uso de **Árvores Binárias de Busca (BST)** na linguagem **C**, aplicando conceitos fundamentais de **estruturas de dados**, **alocação dinâmica de memória**, **recursão** e **manipulação de ponteiros**.

---

## 🎯 Objetivo

O objetivo deste projeto é criar um sistema de gerenciamento de contatos capaz de armazenar e organizar informações de forma eficiente utilizando uma Árvore Binária de Busca.

A aplicação permite cadastrar, localizar, remover e listar contatos em ordem alfabética, explorando na prática o funcionamento de uma estrutura de dados dinâmica.

---

## 🛠️ Tecnologias Utilizadas

* Linguagem C
* Estruturas de Dados
* Árvores Binárias de Busca (BST)
* Ponteiros
* Recursão
* Alocação Dinâmica de Memória

---

## ✨ Funcionalidades

* 📥 Inserir novos contatos.
* 🔍 Buscar contatos pelo nome.
* ❌ Remover contatos cadastrados.
* 📋 Listar todos os contatos em ordem alfabética.
* 🌳 Organização automática dos dados por meio da árvore binária.

---

## 📚 Conceitos Praticados

Durante o desenvolvimento deste projeto foram aplicados diversos conceitos importantes da linguagem C e de estruturas de dados, incluindo:

* Criação e manipulação de nós.
* Inserção em Árvores Binárias de Busca.
* Busca recursiva.
* Remoção de elementos em árvores.
* Percurso em ordem (*In-Order Traversal*).
* Manipulação de ponteiros.
* Gerenciamento de memória com `malloc()` e `free()`.

---

## 🚀 Aprendizados

Este projeto proporcionou uma compreensão mais aprofundada sobre o funcionamento das Árvores Binárias de Busca, permitindo praticar técnicas de organização de dados, otimização de buscas e implementação de algoritmos recursivos em C.

Além disso, contribuiu para o desenvolvimento de habilidades relacionadas à manipulação de memória e à construção de aplicações utilizando estruturas de dados dinâmicas.

---

## ▶️ Como Executar

1. Clone ou baixe o repositório.
2. Compile o arquivo utilizando um compilador C.

```bash
gcc main.c -o contatos
```

3. Execute o programa.

```bash
./contatos
```

4. Utilize o menu para gerenciar os contatos.
